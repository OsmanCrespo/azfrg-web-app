# Portal de Investigação Pesqueira

Site Quarto (R) publicado no GitHub Pages: explorador de mapas, fichas de espécies, dados das pescas e publicações.


## Publicar

Disponibilizar resultados e informações basicas sobre as pesquisas desenvolvidas pela equipa e informações relevantes sobre as principais espécies comerciais dos Açores. 

## Página inicial

Em `index.qmd`, edite os cartões de navegação, a apresentação da equipa, a morada e os membros. A fotografia no topo e no fim da página é `images/OC_edited.png`; o logótipo da apresentação é `images/afg_logo2.png`. Para usar outros ficheiros, atualize as referências em `index.qmd`, incluindo a lista `resources` e o caminho no script que define a imagem da barra superior. Os estilos da página inicial estão em `styles.scss`.
